How to Run Your Own Neo PIP Terminal

Neo PIP Terminal is completely open source! You can run it on your own Mac/PC or cloud VPS with Zero Brokerage on Kotak Neo and Sub-30ms Live Charts on Upstox.

1

Clone the GitHub Repository

Clone the source code to your machine:

git clone https://github.com/thatsaiiff/neo-pip-terminal.git
cd neo-pip-terminal
pip install -r requirements.txt
View on GitHub ↗
2

Kotak Neo Setup (0 Brokerage F&O)

  1. Log in to Kotak Neo Developer Portal.
  2. Copy your Consumer Key and Consumer Secret.
  3. Important: Add your machine / server public IP in the Primary IP whitelist.
  4. Fill in your registered mobile number and UCC.
3

Upstox Setup (Sub-Second Live Data & Option Chain)

  1. Create a free account on Upstox Developer Portal.
  2. Create an app to generate your daily Access Token.
  3. Paste the token into the terminal or set UPSTOX_ACCESS_TOKEN in .env.
4

Configure .env & Launch

# In .env:
LIVE_TRADING_ENABLED=true
NEO_CONSUMER_KEY=your_consumer_key
NEO_MOBILE_NUMBER=+91xxxxxxxxxx
NEO_UCC=your_ucc
UPSTOX_ACCESS_TOKEN=your_upstox_token
OWNER_PIN=2026

# Start server:
uvicorn app.main:app --host 0.0.0.0 --port 8000
